- **功能修复**：修复主页 2 处死链、2 个孤儿页面入口；5 个 canvas 模拟器补高分屏（DPR）适配；抛体运动补 delta-time 物理帧率解耦。
- **安全加固**：密码生成改用加密安全随机数（WebCrypto）；Markdown 预览接入 DOMPurify 防 XSS；外链补 rel="noopener"。
- **体验细节**：补全移动端 viewport、全站 lang 与 favicon；脚本 defer 加载；贪吃蛇 / 打地鼠切后台自动暂停；主页滚动监听 rAF 节流。
