## 📁 项目结构

```
/
├── index.html         # 门户主页：分类导航 / 搜索 / 收藏
├── 404.html           # 404 页面
├── skin.css           # 全站统一设计系统（CSS 变量 + 明暗主题）
├── skin.js            # 主题切换脚本
├── favicon.svg        # 站点图标
├── *.html             # 76 个工具 / 游戏 / 模拟页面（见上表）
└── wdtx.jpg           # 头像资源
```

## 🔧 技术说明

- **零依赖**：全部页面为纯 HTML + CSS + 原生 JavaScript，无框架、无外部 CDN 依赖。
- **统一设计系统**：所有页面引用 `skin.css`，主题色、明暗模式、按钮/输入框/卡片样式全站一致。
- **本地优先**：密码生成（WebCrypto）、哈希计算、加密解密（AES-GCM）、习惯打卡 / 备忘录（localStorage）等均在浏览器本地完成，数据不出站。
- **响应式**：全部页面适配移动端，canvas 模拟器含高分屏（DPR）适配。

## 📝 维护指南

- 新增工具页：复制任意现有页面结构，引用 `skin.css` 与 `skin.js`，在 `index.html` 对应分类下添加卡片即可。
- 主题切换：页面右上角 🌙/☀️ 按钮，选择结果保存在 `localStorage.theme`；深色设计页（模拟器类）默认锁定深色。
- 提交后 GitHub Pages 自动构建，约 1-2 分钟生效。
