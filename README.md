## v1.24（2026-08-06）· 当前版本
- **根治 SW 缓存滞留**：HTML 处理改为 **network-only**（不再从 cache 读取），浏览器普通刷新就能拿到新版，不再依赖硬刷新（Ctrl+Shift+R）。断网时返回 503 提示页（之前会回退到缓存的旧版 HTML，导致版本混乱）。

## v1.23（2026-08-06）
- **修复搜索 searchEmpty 双显**：之前工具索引搜索增强与原 filterProjects 的「没有找到匹配的项目」提示并存，现修复：工具索引有匹配时主动 hide searchEmpty，体验一致。
- **SW 升级提示机制**：SW 在 activate 清旧缓存后通过 postMessage 通知所有打开页面，页面显示「🔄 已更新到 v1.23 · 刷新」气泡（30 秒自动消失），用户无需手动硬刷新即可切到新版；SW 缓存名升级到 `onyes-v1.23`。

## v1.22（2026-08-06）
- **主页搜索增强**：主页搜索可匹配全部 92 个工具名（内置工具索引），输入工具名时下拉显示「工具匹配」并提示所属分类，点击直达分类页并自动带出搜索结果（`?q=工具名` 深链，分类页自动过滤+滚动到首个结果）。

- **PWA 化**：新增 manifest.json + service-worker.js（HTML 走 network-first 保证更新，静态资源 cache-first 提速；SW 版本化，升级自动清旧缓存），主页与 5 个分类页已注册，可安装到桌面/主屏、离线访问核心页。
- **SEO 补齐**：新增 sitemap.xml（100 个页面全收录）+ robots.txt；主页补 OG meta（og:title/description/url）。
- **移动端适配**：分类页补 `@media (max-width:640px)` 响应式规则（卡片内边距/间距/导航微调），静态审查无横向溢出风险。
